# AI handoffs

Create one task brief per independent assignment in `tasks/`. Name it `TASK-001.md`, `TASK-002.md`, and so on. Assign ownership of paths so concurrent agents do not edit the same files. The assignee writes one matching report in `reports/` and leaves the brief in place for history.

Use the templates as a starting point. The root `AGENTS.md` sets repository-wide rules; each task brief defines the scope and acceptance criteria for one assignment.
